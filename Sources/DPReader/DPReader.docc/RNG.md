# Random Number Generation

The random number generators used by Minecraft.

Minecraft uses two random number generators for different purposes. Those are ``CheckedRandom`` (alternatively known as the Java LCG) and ``XoroshiroRandom``.

## Topics

### Random Sources

- ``Random``
- ``CheckedRandom``
- ``XoroshiroRandom``
- ``XoroshiroChunkRandom``

### Random Splitters

Random splitters allow for one random source to be turned into several in a deterministic manner.

- ``RandomSplitter``
- ``CheckedRandomSplitter``
- ``XoroshiroRandomSplitter``
